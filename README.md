# Portfolio - Llorente

A modern ASP.NET Core MVC portfolio application showcasing developer projects, source code repositories, application screenshots, and individual project detail pages with interactive comment sections.

---

---

## ✨ Features

* **Table of Contents / Project Catalog:** Displays a list of developer projects in a modern floating grid layout, complete with thumbnails and short descriptions.
* **Project Detail Pages:** View full descriptions, tech stacks, and direct links to GitHub repositories for each project.
* **Interactive Comment Section:** Post and view comments on each individual project page.
* **Hardcoded Authentication:** Secured routes and user authentication using ASP.NET Core Session/Cookie state.
